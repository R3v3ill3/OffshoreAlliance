# Claude Code — project instructions

## Git workflow

- **Never** use git worktrees or create sub-branches for task work.
- Always work in the primary working directory (`/Volumes/DataDrive/cursor_repos/offshoreAlliance/OffshoreAlliance`).
- Commit directly to the currently checked-out branch (do not switch branches unless explicitly asked).
- Create a single commit per completed feature/fix — not one commit per implementation step or subagent phase.
- Only open a PR when the user explicitly requests one.
- Do not use `EnterWorktree`.
