# System Usability Scale (SUS)

Administered once per participant, at the end of the three tasks, before the
debrief.

**Do not reword these statements.** They are Brooke's standard ten. The only
change allowed is naming the system in place of "this system", and even that
is optional. If you reword an item, drop an item, or change the scale, the
0 to 100 score and the average of 68 stop meaning anything, and the round
cannot be compared with any other round.

Brooke: SUS "is a simple, ten-item scale giving a global view of subjective
assessments of usability"; "SUS scores have a range of 0 to 100"
(https://hell.meiert.org/core/pdf/sus.pdf).

## Scale

1 = Strongly disagree, 5 = Strongly agree.

Every item must be answered. There is no "N/A" and no skipping. If a
participant hesitates, ask them to give the answer closest to how they feel.

## The ten statements

| # | Statement | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | I think that I would like to use this system frequently. | | | | | |
| 2 | I found the system unnecessarily complex. | | | | | |
| 3 | I thought the system was easy to use. | | | | | |
| 4 | I think that I would need the support of a technical person to be able to use this system. | | | | | |
| 5 | I found the various functions in this system were well integrated. | | | | | |
| 6 | I thought there was too much inconsistency in this system. | | | | | |
| 7 | I would imagine that most people would learn to use this system very quickly. | | | | | |
| 8 | I found the system very cumbersome to use. | | | | | |
| 9 | I felt very confident using the system. | | | | | |
| 10 | I needed to learn a lot of things before I could get going with this system. | | | | | |

## Scoring

For each item, take the answer x (1 to 5) and convert it:

- Odd items (1, 3, 5, 7, 9): score = x minus 1.
- Even items (2, 4, 6, 8, 10): score = 5 minus x.

Add the ten converted scores. Multiply the total by 2.5. The result is the
participant's SUS score, from 0 to 100.

Report the mean across participants.

## Two things to remember when reporting

- **SUS is not a percentage.** A score of 72 does not mean 72% of anything.
- **The average SUS score is 68.** Anything below that is below average, not
  merely "a bit low".

Both points from MeasuringU, "10 things to know about the System Usability
Scale": https://measuringu.com/10-things-sus/
