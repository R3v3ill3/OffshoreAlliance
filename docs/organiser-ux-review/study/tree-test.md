# Tree test: the four-tab campaign workspace

Run this **before phase 1 is built** (plan section 8, method paragraph).
Allow 15 minutes.

A tree test evaluates a proposed navigation hierarchy: it assesses "the
findability of resources after you have created your proposed navigation
hierarchy". Card sorting generates an architecture, tree testing evaluates one
(https://www.nngroup.com/articles/tree-testing/ ;
https://www.nngroup.com/articles/card-sorting-tree-testing-differences/).

## How to run it

- **Text only.** No screens, no mockups, no icons, no colour. The participant
  reads a list of labels and points at one.
- Show the top level only. When they pick a top-level label, show that
  label's children. Then ask "is what you were looking for here, or would you
  go back?"
- **No back-channel hints.** Do not react to a wrong choice. Do not say "are
  you sure". Let them go all the way down and let them backtrack.
- Record the path they took and whether they backtracked.

## The find-tasks

Phrase every task as a goal. Do not use a label word from the tree in the task
wording, or the participant is matching keywords rather than finding things.

Read one at a time. Use 8 to 10 of these.

1. See how a shift is tracking.
2. Change who is in the campaign.
3. Add a shift to the campaign.
4. Find who else is organising this campaign.
5. Send a text to a list of workers.
6. See the assessments recorded last week.
7. Change the campaign's start date.
8. Open the campaign's strategic plan.
9. Find a document about the agreement.
10. See how the campaign is going overall.

## What to record

Per task, per participant:

| Field | Value |
|---|---|
| Task number | |
| First click (top-level label) | |
| Final destination | |
| Correct or incorrect | |
| Backtracked | yes / no |
| Seconds | |

Decide the correct destination for each task **before** the sessions start,
and write it down. Deciding afterwards turns a wrong answer into a right one.

Report first-click accuracy separately from final accuracy. A tree where
people get there in the end but start in the wrong place is still the wrong
tree.
